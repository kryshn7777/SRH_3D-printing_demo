# Project Lessons & Persistent Memory

- **Repository Target**: All commits and pushes for this project go to `https://github.com/kryshn7777/SRH_3D-printing_demo` (`origin` / `main` branch).
- **GitHub Pages Hosting**: The project is hosted on GitHub Pages at `https://kryshn7777.github.io/SRH_3D-printing_demo/`. When pushing updates, push source to `main` and publish `dist/` (including `404.html` copied from `index.html`) to the `gh-pages` branch.
- **Pre-Push Verification**: Always ensure `.gitignore` excludes `node_modules/`, `dist/`, and `.playwright-mcp/`, and verify `npm run build` passes before pushing.
